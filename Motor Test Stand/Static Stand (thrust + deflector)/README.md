# Motor Test Stand — Ground Support Equipment

Printable **PETG-CF** parts for the vertical load-cell thrust stand that produces the **RQ1
static thrust-curve baseline** (Estes F15-0 and E16-4). PETG-CF here is a GSE choice, not a
vehicle-material choice — the fixture sits beside a 3.45 s plume, so it does not follow the
vehicle's PLA-primary rule. Jetvane coupon testing was dropped from the program in 2026-08;
this stand is axial-thrust only.

- `TS_base_plate.*` — staked ground plate.
- `TS_motor_tower.*` — vertical motor cradle + load-cell seat.
- `TS_loadcell_bracket.*` — bar load-cell mounting bracket.

Instrumentation: Wishiot 10 kg bar load cell + HX711, read by an Adafruit Metro M4 logging to microSD, calibrated with known hanging masses to ~2.5 kg, then commissioned against a published E16-4 curve. Generated by `../../3D parts/_generator/gen_rocket4.py`.
