# Motor Test Stand, Ground Support Equipment

Printable **PETG-CF** parts for the vertical load-cell thrust stand that produces the **RQ1
static thrust-curve baseline** (Estes F15-0 and E16-4). PETG-CF here is a GSE choice, not a
vehicle-material choice, the fixture sits beside a 3.45 s plume, so it does not follow the
vehicle's ASA-Aero/PETG-CF/PC-FR zoning. Jetvane coupon testing runs on this same stand (see
`WYVERN_E4_GSE_TestStands.md` §1) as a blast-shield materials screen, not a vane-deflection test;
this stand's own printed geometry below is axial-thrust-only regardless.

- `TS_base_plate.*`, ground plate, bolts the motor tower and load-cell bracket down and provides
  4 corner mounting bosses.
- `TS_motor_tower.*`, vertical motor cradle (29mm-class F15 case, slip fit) + load-cell seat.
- `TS_loadcell_bracket.*`, bar load-cell mounting bracket (fixed end + sensing-end interface).

**Instrumentation:** **1x 5 kg axial load cell + HX711**, read by a Raspberry Pi Pico / Pico 2 W
DAQ at 80 SPS, matching `WYVERN_E4_GSE_TestStands.md` §1. Calibrated with known hanging masses to
~2.5 kg, then commissioned against a published E16-4 curve.

Generated by `../../3D parts/_generator/gen_rocket4.py`. Fastener standard: M3 heat-set brass
inserts (4.2mm pilot, 8mm boss OD) at every bolted joint; load-cell hole spacing is a
TYPICAL-CLASS figure for the Adafruit 5kg strain-gauge cell, verify with calipers against the
actual part before the final print (see the generator's module docstring).
